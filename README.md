# invitecraft

돌잔치 초대장, 청첩장 등 다양한 행사 초대장을 날짜별 폴더로 관리하고 GitHub Pages로 배포하는 프로젝트입니다.

## 폴더 규칙
- 각 초대장은 루트에 `YYYY-MM-DD_초대장이름` 형식의 폴더로 생성합니다.
- 각 폴더의 `invite.config.json`에 GitHub Pages 배포 경로(`slug`)와 메타 정보를 정의합니다.
